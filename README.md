# CI Pipeline Python App

This project demonstrates a basic Continuous Integration (CI) pipeline using GitHub Actions.

## Features

- Simple Python application
- Unit testing with pytest
- Code quality checks with flake8
- Automated CI pipeline on every push

## CI Pipeline

The pipeline runs automatically when code is pushed to the main branch.

Steps:
1. Checkout source code 
2. Set up Python environment
3. Install dependencies
4. Run lint checks (flake8)
5. Execute tests (pytest)

## Tech Stack
- Python
- GitHub Actions
- pytest
- flake8
